enbeep

v2 acoustic modem — send + receive beeped messages
by TIKOCI

enbeep sends short messages as beeps — sixteen pitches a microphone can hear and check. Pick a sender below, then listen here or on a second device. It is an experiment: quiet rooms and matching symbol lengths matter.

A — Send from a MikroTik router

  1. In a router terminal, check the beeper: :beep frequency=4000 length=500ms. No sound means no sender on this box.
  2. Load the encoder into that terminal — pick one:
    Option 1 — paste (works everywhere): copy the whole script, paste it:
    Show enbeep.rsc 
    Loading…
    Option 2 — fetch (experimental: needs the router to reach this site; CHR-verified, one 7.16 hardware check still open): paste this one line, no file download: 
    loading…
    Globals are RAM-only: reload after reboot. (plain file.)
  3. Dry-run silently (edit the message, keep the quotes plain): 
    $enbeepText "Hello" 200ms 200ms yes
    Expect FRAME and T: lines. Anything else means the load failed — repeat step 2.
  4. On the listener, open the Decode tab, pick the same symbol length, press Start Listening, and hold the mic ~0.3 m from the beeper.
  5. Back on the router, play it for real: 
    $enbeepText "Hello" 200ms 200ms no
    Keep the terminal connected through the frame (~13 s at 200 ms). The MAC/IP announce variant is $enbeepAnnounce "bridge" 0 200ms 200ms no (interface + address row are yours to choose).

B — Send from this speaker

One device's speaker stands in for the router — same v2 tones and checksum. Type a message, play it, and listen on a second device.

Sender and receiver must use the same symbol length (Decode tab). This page also decodes its own playback — only the other device's result proves sound crossed the room.

If it fails

Check the symbol match first, then distance, speaker volume, and room noise. Rejections are data: open Diagnostics → Copy diagnostics report while the attempt is still on screen — the report keeps your last session across one reset. Slow or quiet beeper? Try 400 ms both sides.

Then listen

The beeps need a listener: on this or another system showing this page, open the Decode tab, pick the same symbol length, and press Start Listening before the sender plays.

Ready
Self-test checks the decoder without a mic and plays a fixed demo frame through the speaker. Stop listening first — it can't share a mic session. A second device can listen; only its result tests the acoustic path. To send your own message, use the Try it tab.
